
# Dokumentasi Praktik Git dan GitHub

## Tujuan
Menerapkan version control menggunakan Git dan GitHub
dalam pengembangan proyek Disty HelpDesk.

## Aktivitas
1. Clone repository dari GitHub.
2. Memeriksa status dan riwayat repository.
3. Membuat branch baru untuk pengembangan.
4. Melakukan perubahan dokumentasi proyek.
5. Melakukan staging dan commit.
6. Mengirim perubahan ke GitHub menggunakan push.
7. Membuat Pull Request.
8. Melakukan review dan merge ke branch main.
9. Melakukan sinkronisasi repository lokal.

## Hasil
Praktik ini bertujuan memahami pengelolaan versi kode,
kolaborasi, dan alur pengembangan menggunakan Git
dan GitHub pada proyek Disty HelpDesk.
